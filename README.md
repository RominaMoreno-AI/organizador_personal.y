# Organizador Personal

## Objetivo
Preparar la estructura inicial de una aplicación que, en el futuro, podrá
administrar tareas y notas personales.

## Tecnologías utilizadas
- Python 3
- requests
- python-dotenv

## Pasos de instalación
1. Clona este repositorio.
2. Crea el entorno virtual: `python -m venv .venv`
3. Actívalo (Windows: `.venv\Scripts\activate` / macOS-Linux: `source .venv/bin/activate`)
4. Instala las dependencias: `pip install -r requirements.txt`
5. Ejecuta el proyecto: `python src/main.py`
