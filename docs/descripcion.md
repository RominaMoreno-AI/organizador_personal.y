# Descripción del proyecto

Organizador Personal es una aplicación pensada para ayudar a una persona a
administrar sus tareas y notas del día a día. En esta etapa inicial, el
proyecto solo define la estructura base (carpetas, documentación y entorno
de trabajo); la lógica de la aplicación se desarrollará en etapas futuras.

El objetivo a mediano plazo es que el usuario pueda registrar pendientes,
darles seguimiento y llevar notas personales desde un mismo lugar.
